Clip length around speech

How much audio to keep before speech starts and after it stops. More context helps transcription but adds silence.

Skip near-silent clips

Clips quieter than this are marked “no speech” without transcribing them. 0 turns it off. The default 0.005 only skips near-total silence.

Compress older audio

Audio older than this many days is converted to Opus (about a tenth of the size, still fine for listening). 0 keeps everything as WAV.

Catch missed events

The model installed on the speaches server that turns audio into text. Changing it applies to new clips; use Maintenance → Re-transcribe to redo old ones.

Language

Skip silence inside clips

Voice activity detection cuts silent stretches before recognition. It is faster and prevents most invented text, so leave it on.
